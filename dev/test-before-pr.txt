
 一、本次 Agent 可执行的静态检查

 ```powershell
   pnpm exec tsc --noEmit
   pnpm lint
   # pnpm format:check
   # pnpm i18n:check
   cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
   git diff --check
 ```

 ### 各命令作用

 ┌────────────────────────┬─────────────────────────────────────────────────────┐
 │ 命令                   │ 作用                                                │
 ├────────────────────────┼─────────────────────────────────────────────────────┤
 │ pnpm exec tsc --noEmit │ 只做 TypeScript 类型检查，不生成文件、不构建        │
 ├────────────────────────┼─────────────────────────────────────────────────────┤
 │ pnpm lint              │ 检查 console 使用和 Biome 代码质量问题              │
 ├────────────────────────┼─────────────────────────────────────────────────────┤
 │ pnpm format:check      │ 检查 src/ 的 Biome 格式，不修改文件                 │
 ├────────────────────────┼─────────────────────────────────────────────────────┤
 │ pnpm i18n:check        │ 检查四份 locale JSON 的格式；不检查翻译内容是否完整 │
 ├────────────────────────┼─────────────────────────────────────────────────────┤
 │ cargo fmt ... --check  │ 检查 Rust 格式，不修改文件                          │
 ├────────────────────────┼─────────────────────────────────────────────────────┤
 │ git diff --check       │ 检查尾随空格、空白错误等补丁问题                    │
 └────────────────────────┴─────────────────────────────────────────────────────┘

 按新规范：每项最多执行一次，不并行，不失败重试。

 二、提交前必须人工检查

 ```powershell
   git status --short
   git diff --stat
   git diff --name-only
 ```


  Git 检查命令

  ┌──────────────────────┬────────────────────────────────────┬──────────────┐
  │ 命令                 │ 作用                               │ 是否产生文件 │
  ├──────────────────────┼────────────────────────────────────┼──────────────┤
  │ git status --short   │ 查看已修改、已暂存、未跟踪文件     │ 否           │
  ├──────────────────────┼────────────────────────────────────┼──────────────┤
  │ git diff --stat      │ 查看未暂存改动的文件数量和行数统计 │ 否           │
  ├──────────────────────┼────────────────────────────────────┼──────────────┤
  │ git diff --name-only │ 列出未暂存改动的文件名             │ 否           │
  ├──────────────────────┼────────────────────────────────────┼──────────────┤
  │ git diff --check     │ 检查尾随空格、空白错误等           │ 否           │
  └──────────────────────┴────────────────────────────────────┴──────────────┘

  注意：git diff --stat/name-only 默认不显示未跟踪文件，因此必须结合：

  ```powershell
    git status --short
  ```

  暂存后检查建议使用：

  ```powershell
    git diff --cached --stat
    git diff --cached --name-only
    git diff --cached --check
  ```

  查看当前提交相对 HEAD 的全部改动：

  ```powershell
    git diff HEAD --stat
    git diff HEAD --name-only
  ```

 重点确认：

 - 只包含本次 PR 相关文件
 - 没有误提交 dist/、target/、临时文件
 - 后端字段和前端字段一致：
     - modelRiskReason
     - localRiskReasonCode
     - approvalReasonCode
 - 四种语言都包含新增的 i18n key
 - 运行中的审批按钮没有被改坏

 当前工作区中：

 ```text
   AGENTS.md
   Agent-execution-policy-dev.md
 ```

 是用户侧规范文件改动，不要自动纳入本次 PR，除非你明确希望一起提交。

 三、交给用户或 CI 的完整验证

 这些不由本 Agent 执行，但建议由 CI 或你本地验证：

 ```powershell
   pnpm build
   cargo check --manifest-path src-tauri/Cargo.toml
   cargo test --manifest-path src-tauri/Cargo.toml
   cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets
 ```

  构建与 Rust 检查

  ┌───────────────────────────────────────────────────────────┬───────────────────────────────────────────────────────┬───────────────────────────────────────────────────────────────────┐
  │ 命令                                                      │ 作用                                                  │ 是否产生大文件                                                    │
  ├───────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────┤
  │ pnpm build                                                │ 执行 build:mcp-sidecar、TypeScript 检查、Vite 前端构  │ 会。生成 dist/、MCP release 构建产物，并复制二进制到              │
  │                                                           │ 建                                                    │ src-tauri/binaries/                                               │
  ├───────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────┤
  │ cargo check --manifest-path src-tauri/Cargo.toml          │ 检查 Rust 是否能编译，但不生成最终可执行程序          │ 会。会产生或更新 src-tauri/target/ 编译缓存，可能较大             │
  ├───────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────┤
  │ cargo test --manifest-path src-tauri/Cargo.toml           │ 编译并执行 Rust 单元测试/集成测试                     │ 会。会产生测试二进制和 target/ 缓存；不会生成安装包               │
  ├───────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────┤
  │ cargo clippy --manifest-path src-tauri/Cargo.toml         │ Rust 静态分析，--all-targets 会检查库、二进制、测试等 │ 会。复用或增加 target/ 编译产物；不会修改源码                     │
  │ --all-targets                                             │ 目标                                                  │                                                                   │
  └───────────────────────────────────────────────────────────┴───────────────────────────────────────────────────────┴───────────────────────────────────────────────────────────────────┘

  注意：pnpm build 会间接执行 cargo build --release 来构建 MCP sidecar。

  删除，防止一次次测试空间膨胀：

   # 删除前端构建产物
   Remove-Item -Recurse -Force .\dist -ErrorAction SilentlyContinue
   Remove-Item -Recurse -Force .\dist-ssr -ErrorAction SilentlyContinue

   # 删除 MCP sidecar 复制出的二进制
   Remove-Item -Force .\src-tauri\binaries\nyaterm-mcp-* -ErrorAction SilentlyContinue

   # 删除主 Rust 构建缓存
   Remove-Item -Recurse -Force .\src-tauri\target -ErrorAction SilentlyContinue

   # 删除 MCP 独立 Rust 构建缓存
   Remove-Item -Recurse -Force .\src-tauri\crates\nyaterm-mcp\target -ErrorAction SilentlyContinue
